# FP&A Budget, Actual & Forecast Model

An end-to-end **FP&A portfolio case study** built in Excel to simulate the planning, forecasting, variance analysis, scenario modeling, and management reporting responsibilities of an FP&A analyst.

> **Portfolio disclosure:** Northstar Consumer Distribution and all figures in this project are fictional. The workbook was created for skills demonstration and contains no confidential employer data.

## Project Objective

Build a management-ready financial planning model that connects historical actuals, an annual budget, a rolling forecast, operating drivers, scenario analysis, working capital, and executive reporting in one auditable workbook.

## Model Highlights

- **Actuals, Budget & Rolling Forecast** — FY2026 planning model with Jan-Sep actuals and Oct-Dec forecast
- **Driver-Based Forecasting** — revenue, gross profit and operating expenses linked to operating assumptions
- **Scenario Analysis** — Base, Upside and Downside cases flow through the forecast
- **Product Profitability** — units, revenue, COGS, gross profit and gross margin by product line
- **Department Planning** — departmental budget ownership and variance visibility
- **Working Capital & Cash** — AR, inventory, AP and cash-flow implications
- **Variance Analysis** — Budget vs Forecast with dollar and percentage variances
- **Forecast Accuracy** — tracking of forecast performance against actual results
- **Sensitivity Analysis** — EBITDA sensitivity to key commercial and cost drivers
- **Executive Dashboard** — KPI cards, trends, scenario comparison and management takeaways
- **Model Checks** — reconciliation and integrity controls

## Management Story

The model demonstrates how FP&A can translate operating assumptions into a financial outlook and explain performance to management. In the modeled FY2026 forecast, revenue is slightly below budget while EBITDA remains above budget, highlighting the importance of gross-margin and cost management when topline performance softens.

## Workbook Structure

| Area | Purpose |
|---|---|
| Control Panel | Reporting period, scenario selection and core assumptions |
| Actuals | Historical product-level operating and financial data |
| Revenue / OPEX Builds | Driver-based planning schedules |
| Budget | Monthly FY2026 budget |
| Forecast | Actuals plus remaining-period forecast |
| Driver Forecast | Scenario-sensitive forward forecast |
| P&L | Consolidated financial view |
| Variance Analysis | Budget vs forecast performance |
| Scenarios | Base / Upside / Downside assumptions |
| Product Profitability | Product-line economics and margins |
| Department Budget | Department-level planning and accountability |
| Working Capital | AR, inventory, AP and cash implications |
| Forecast Accuracy | Forecast error monitoring |
| Sensitivity Analysis | EBITDA response to key assumptions |
| Executive Dashboard | Management reporting view |
| Model Checks | Reconciliation and integrity controls |
| Case Study | Project context and model guide |

## FP&A Skills Demonstrated

Financial modeling · Budgeting · Rolling forecasting · Driver-based planning · Variance analysis · Scenario planning · Management reporting · KPI development · Product profitability · Working-capital analysis · Forecast accuracy · Sensitivity analysis · Financial storytelling

## How to Use

1. Open the Excel workbook.
2. Review the **Case Study** and **Control Panel** tabs.
3. Select a scenario in the Control Panel.
4. Review the impact across the Driver Forecast, P&L and Executive Dashboard.
5. Use the Variance Analysis and management commentary to interpret the business drivers.
